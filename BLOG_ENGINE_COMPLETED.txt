================================================================================
                           QUICK START (5 MINS)
================================================================================

1. Install Dependencies:
   $ pip install anthropic python-dotenv google-auth-oauthlib \
     google-auth-httplib2 google-api-python-client requests

2. Get Google Credentials:
   - Download from Google Cloud Console
   - Save as google_photos_credentials.json
   - Save as google_drive_credentials.json

3. Set Email Password:
   - Gmail: Settings → 2-Factor Auth → App Passwords
   - Update .env: EMAIL_PASSWORD=your_16_char_password

4. Create Customer Email List:
   $ echo "customer@example.com" > customer_emails.txt

5. Test It:
   $ python blog_scheduler.py

Expected output: One blog post generated → saved to blogs/ → email sent!

================================================================================
                        TROUBLESHOOTING
================================================================================

"credentials.json not found"
  → Download from Google Cloud Console
  → Save in project root as google_photos_credentials.json

"SMTP login failed"
  → Use 16-char app password (not regular Gmail password)
  → Enable 2-factor authentication
  → Verify EMAIL_SENDER matches your Gmail

"No unprocessed photos found"
  → Upload photos to Google Photos account
  → Or clear blog_tracker.json to reset

"Blog generation failed: Rate limit"
  → Claude API rate limit (wait 5 mins)
  → Or schedule at different time of day

See BLOG_SETUP_GUIDE.md for complete troubleshooting section.
