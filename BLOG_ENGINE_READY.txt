⬇️  STEP 1: ADD GOOGLE CREDENTIALS (5-10 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open browser: https://console.cloud.google.com/
2. Sign in with your Google account
3. Create new project: "Los Iconos Blog"
4. Enable these APIs:
   ✓ Google Photos Library API
   ✓ Google Drive API
5. Create OAuth 2.0 Client ID (Desktop application)
6. Download JSON file
7. Run: python add_credentials.py
   → Choose: "1. Google OAuth credentials"
   → Paste the JSON content
   → Done!

📖 For detailed steps with screenshots: read GET_GOOGLE_CREDENTIALS.md

⬇️  STEP 2: ADD GMAIL APP PASSWORD (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://myaccount.google.com/
2. Click: Security (left sidebar)
3. Enable: 2-Factor Verification (if needed)
4. Then: App passwords
5. Choose: Mail + Windows Computer
6. Generate password (16 characters)
7. Run: python add_credentials.py
   → Choose: "2. Gmail app password"
   → Paste the 16-char password
   → Done!

The password is automatically saved to .env

⬇️  STEP 3: ADD YOUR CUSTOMER EMAILS (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Run: python add_credentials.py
   → Choose: "3. Customer emails"
   → Enter emails one per line
   → Press Enter twice when done
   → Done!

Or manually edit: customer_emails.txt

💡 TIP: Export from Shopify
   Admin → Customers → Export → Copy email column → paste into file
