WHAT WE BUILT

A complete automated daily blog posting system that:

  📸 Pulls photos from Google Photos (oldest first)
  📄 Gathers related docs from Google Drive (same date)
  🔍 Researches topics via web search (free DuckDuckGo)
  ✍️  Generates 800-1200 word blog posts using Claude AI
  💾 Saves HTML blogs to your server
  📧 Sends promotional emails to customers
  ✅ Tracks processed photos (prevents duplicates)
  ⏰ Runs automatically at 9 AM every day

HOW IT WORKS

DAILY AT 9:00 AM:

  [1] Fetch oldest unposted photo from Google Photos
      |
  [2] Find related Google Drive documents (same date)
      |
  [3] Search web for additional context & research
      |
  [4] Claude AI synthesizes all sources into blog post
      |
  [5] Save HTML blog post to blogs/ directory
      |
  [6] Send promotional email to all customers
      |
  [7] Mark photo as processed (prevent duplicates)
      |
  [8] Sleep 23 hours, repeat tomorrow

SETUP IN 3 STEPS

1. GET GOOGLE CREDENTIALS (5-10 minutes)
   - Go to Google Cloud Console
   - Create project "Los Iconos Blog"
   - Enable Photos Library API + Drive API
   - Download OAuth JSON
   - Run: python add_credentials.py

2. ADD GMAIL APP PASSWORD (5 minutes)
   - Go to myaccount.google.com Security
   - Generate app password (16 chars)
   - Run: python add_credentials.py

3. UPDATE CUSTOMER EMAILS (2 minutes)
   - Edit customer_emails.txt
   - Add your customer emails
   - Save
